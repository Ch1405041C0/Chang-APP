# Chang@ App — Starter móvil

Migración móvil del prototipo ChangAI.

## Objetivo

**Trabajo → historial verificable → formalización → progreso real → beneficios reales.**

Chang@ no busca gamificar con puntos o monedas ficticias. El progreso representa hechos reales del trabajador y los beneficios deben existir fuera de la app.

## Principios

- Sin monedas virtuales, rachas, rankings ni pérdida artificial de progreso.
- Todo progreso representa trabajo real.
- Todo beneficio debe existir fuera de Chang@.
- El historial pertenece al trabajador.
- La IA interpreta, resume y recomienda; las decisiones sensibles quedan bajo reglas auditables.
- La complejidad fiscal e institucional queda detrás de una experiencia simple.

## Estructura inicial

- `src/theme.ts`: identidad visual heredada de ChangAI.
- `src/domain.ts`: modelos de dominio.
- `src/demo.ts`: estado demo.
- `src/benefits.ts`: motor determinístico de beneficios.
- `src/App.tsx`: MVP navegable.
- `docs/PRODUCT.md`: principios de producto.
- `docs/BACKEND.md`: arquitectura backend objetivo.
