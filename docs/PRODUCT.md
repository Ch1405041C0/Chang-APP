# Chang@ — Principio de producto

Chang@ conecta a trabajadores independientes con trabajo y convierte cada actividad real en historial verificable.

## Core loop

1. Encontrar o recibir trabajo.
2. Realizarlo.
3. Registrar cobro y actividad.
4. Construir historial.
5. Mostrar progreso real.
6. Detectar beneficios reales.
7. Permitir solicitarlos con mínima fricción.
8. Usar datos agregados y protegidos para demostrar capacidad productiva.

## Regla ética

Chang@ no debe ganar porque al trabajador le vaya peor.

No usar:
- monedas virtuales;
- rachas artificiales;
- pérdida de progreso;
- rankings humillantes;
- deuda como mecanismo de retención;
- FOMO artificial.

## Norte institucional

La plataforma debe poder demostrar, con consentimiento y privacidad:
- cantidad de trabajadores activos;
- oficios y capacidades;
- disponibilidad;
- trabajos realizados;
- continuidad;
- zonas;
- capacidad productiva agregada.
